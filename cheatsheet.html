RA Read Aloud 실전 전략

  • 3초 무음 주의: 마이크가 켜지고 3초간 소리가 없으면 자동으로 녹음이 종료됩니다. 비프음 후 즉시 발화를 시작하세요.
  • 발음보다 유창성이 우선: 모르는 단어가 나와도 멈추거나 더듬지 말고 자연스러운 억양으로 흘려 넘기는 것이 고득점의 핵심입니다.
  • 구두점(쉼표, 마침표)에서만 짧게 멈춤: 문장 중간에서 멈추면 Pause 감점으로 Fluency 점수가 급락합니다.

DI Describe Image 79+ 만능 템플릿

  • 도표의 종류(막대/원형/지도/사진)에 상관없이 아래 4단계 구조를 35초간 쉬지 않고 말하면 만점입니다.
1. [도입] The given image provides informative data about [제목/주제].
2. [최댓값] According to the chart, the highest figure can be observed in [최댓값 항목].
3. [최솟값] Conversely, the lowest figure is shown in [최솟값 항목].
4. [결론] In conclusion, it can be clearly seen that [전체적인 핵심 추세].

WE Write Essay 4단락 표준 프레임

  • 분량 세이프티 존: 반드시 220~260단어 사이로 작성하세요. (200단어 미만이나 300단어 초과 시 Form 점수 감점).
  • 서론(35단어) - 본론1(75단어) - 본론2(75단어) - 결론(45단어) 4단락 구조를 지키면 Structure 만점입니다.

WFD Write from Dictation 방어 전략

  • 단수/복수 방어법: 단수인지 복수인지 헷갈릴 때는 둘 다 작성(예: assignment assignments)해도 맞는 단어가 감지되면 점수를 획득합니다.
  • 약어 메모법: 들리는 즉시 단어의 첫 2~3글자만 종이에 적고(예: lib wil be clo...), 오디오가 끝난 뒤 온전한 단어로 복원하세요.

ROP Re-order Paragraphs 인접 쌍(Pair) 공략법

  • 독립적인 첫 문장(Topic Sentence) 찾기: 대명사(he, she, they, it), 지시어(this, these), 역접 접속사(however, therefore)로 시작하지 않는 완전하고 자립적인 문장을 무조건 1번으로 배치하세요.
  • 피어슨 공식 쌍(Pair) 채점 원리: 전체 순서가 하나 틀려도 인접한 두 문단의 순서(예: B-A, A-C)만 맞으면 부분 점수를 획득합니다. 문단과 문단 사이의 '지시어 고리(This process, These gases)'를 연결하세요.
  • 시간 순서 및 원인-결과 파악: 과거 연도/과거 시제(Before the 15th century)가 먼저 나오고, 현대/현재 시제(Today, Nowadays)가 뒤에 배치됩니다.

SST Summarize Spoken Text 50~70단어 만능 템플릿

  • 분량 엄수: 무조건 50단어 이상, 70단어 이하로 작성하세요. (49단어 이하이거나 71단어 초과 시 1점 감점, 100단어 초과 시 0점 처리).
  • 아래 템플릿 빈칸에 강의에서 메모한 핵심 명사구 4~5개만 채워 넣으면 문법과 어휘 만점을 받습니다.
The lecture mainly discussed [핵심 주제]. The speaker stated that [핵심 포인트 1]. Furthermore, he emphasized that [핵심 포인트 2], which significantly affects [핵심 포인트 3]. In conclusion, the presentation provided valuable insights into [전체 요약].

RL Retell Lecture 79+ 스피킹 만능 프레임

  • 강의를 다 알아듣지 못했더라도 메모한 명사 키워드 4개만 아래 구조에 넣어 35초간 끊김 없이 말하면 유창성 만점입니다.
1. The speaker provided an informative analysis about [강의 주제].
2. Firstly, he discussed the importance of [메모한 키워드 1].
3. Secondly, he emphasized the significant impact of [메모한 키워드 2].
4. Overall, the lecture clearly illustrated key concepts regarding [메모한 키워드 3].
